# Thiết kế Wireframe và Sơ đồ hành trình du khách
- **Hành trình 1:** Du khách tìm kiếm điểm đến -> xem điểm số danh tiếng -> đọc phân tích khía cạnh -> đặt vé/dịch vụ.
- **Hành trình 2:** Chủ cơ sở đối tác theo dõi danh tiếng cơ sở -> xem đánh giá tiêu cực -> nhận diện sự cố vệ sinh/phục vụ.
- **Hành trình 3:** Quản trị viên theo dõi dashboard -> nhận cảnh báo khủng hoảng -> phê duyệt hoặc ẩn đánh giá giả mạo.
